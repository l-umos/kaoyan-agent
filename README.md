# 🎓 考研学习规划 Agent

一个 AI Agent 驱动的交互式考研学习规划网页应用。单文件、纯前端、开箱即用，也是我的 AI Agent 简历作品项目。

**在线演示：<https://l-umos.github.io/kaoyan-agent/>**

## ✨ 功能特性

- 🤖 **真实 LLM + 工具调用**：在页面填入自己的 API Key（支持 DeepSeek / OpenAI / Kimi / 通义等 OpenAI 兼容接口），对话就由真实大模型驱动——分析你的问题 → 调用规划函数 → 更新计划 → 生成建议，Agent 工作台全程可见
- 📚 **知识库（RAG）**：上传考研大纲、专业课目录（.txt / .md / .json / .csv 或直接粘贴），问"408 网络这章重点是什么"时自动检索资料作答并标注来源
- 🎛️ **科目自选**：政治必考；英语可选英一 / 英二；数学可选数一 / 数二 / 数三 / 不考；专业课 408 可开可关，组合切换后章节结构与计划自动更新
- 🗺️ **分阶段规划**：基础 → 强化 → 真题 → 冲刺四轮制，自动推算每轮起止日期、各科学时分配和考前可完成轮数
- 🔁 **艾宾浩斯复习**：单词按 1 / 3 / 7 / 15 / 30 天节点滚动复习，新学章节按 1 / 3 / 7 天安排复盘
- ✅ **任务管理**：自动生成今日 / 本周任务，支持打卡、修改、新建、删除、归档与恢复
- ⏱️ **计时器浮窗**：正计时 / 倒计时 / 番茄钟（25+5），可关联科目，可拖动，结果自动写入统计
- 🎯 **闯关自测**：7 个科目题库，难度自适应，实时打分与评级，成绩反馈到掌握度
- 📊 **统计与总结**：学习热力图（可点击）、各科学时分布、AI 生成每日 / 整体学习总结

## 🚀 快速开始

1. 下载 `index.html`
2. 用 Chrome / Edge 等浏览器双击打开
3. 选择考试科目，填写当前进度，开始使用
4. （可选）点击右上角「🔑 LLM 设置」填入你的 API Key，解锁真实 LLM 对话与知识库问答

无需安装、无需后端服务器。未配置 LLM 时自动使用内置规则引擎。

## 🧠 Agent 设计

右侧「Agent 工作台」全程透明展示决策过程：

**感知环境 → 读取目标 → 调用工具计算 → 规划轮次 → 分配任务 → 安排复习 → 反思建议**

配置 LLM 后，对话会走完整的工具调用闭环：LLM 输出 JSON 工具调用（更新进度 / 设置优先级 / 调整每日学时 / 重新规划 / 检索知识库）→ 应用执行 → 结果回传 → LLM 生成最终建议。内置规则引擎作为无 Key 时的降级方案。

## 📌 使用说明

- 数据保存在浏览器本地（localStorage），不会上传到任何服务器；API Key 同样只存在本浏览器
- 内置科目结构：政治 13 章、英一 / 英二各 11 章、数一 22 章、数二 13 章、数三 20 章、408 共 26 章（数据结构 8 / 计组 7 / 操作系统 5 / 网络 6）
- 进度、任务、学习记录都可以通过页面右上角「重置」一键清空
